# Shat Company Platform (منصة شركة شات للتنمية والتطوير)

منصة رقمية مؤسسية متعددة اللغات لـ **شركة شات للتنمية والتطوير (SHAT Development & Growth)**، متخصصة في التدريب، بناء القدرات، الاستشارات، والتطوير المؤسسي وفق المعايير الدولية والإنسانية.

---

## 🌟 مميزات المنصة الرئيسية

1. **انتقال مستقل إلى صفحات جديدة (Multi-Page Route Navigation)**:
   - تم تصميم الأقسام الثمانية بحيث ينتقل المستخدم إلى **صفحة كاملة جديدة** لكل قسم مع مسار تصفح (Breadcrumbs)، وتبويبات فرعية لكل قسم، وليس مجرد نزول (Scroll) في نفس الصفحة.
   - التزام تام بطلب العميل: **عدم كتابة أي أرقام بجانب أسماء الأقسام**.

2. **دعم كامل لـ 5 لغات دولية مع تبديل فوري**:
   - 🇸🇦 **العربية (AR)**: واجهة كاملة من اليمين لليسار (RTL) مع خطوط Cairo و Tajawal.
   - 🇬🇧 **English (EN)**: واجهة كاملة (LTR) مع خطوط Outfit و Inter ومصطلحات التنمية الدولية.
   - 🇫🇷 **Français (FR)**: واجهة فرنسية متكاملة للمنظمات الدولية والإنسانية.
   - 🇪🇸 **Español (ES)**: واجهة إسبانية دقيقة ومعتمدة للتطوير المؤسسي.
   - 🇮🇹 **Italiano (IT)**: واجهة إيطالية احترافية لبرامج التعاون الدولي والتدريب.

3. **الأقسام المؤسسية الثمانية (مع الأقسام الفرعية بداخل كل قسم)**:
   - **نبذة عن شات** (About SHAT): من نحن، المنهجية، فلسفة شات ونموذج الأثر، الهوية المؤسسية.
   - **ما الذي نقدمه** (What We Do): منظومة التدريب وبناء القدرات (7 محاور)، منظومة الاستشارات والتطوير المؤسسي (8 محاور).
   - **التخصصات الاستشارية والتقييم** (Specialized Consulting & Evaluation): استشارات الحماية وصون السلامة (PSEA)، والتقييم الخارجي المستقل وفق معايير OECD DAC الستة.
   - **نموذج العمل** (Our Delivery Model): المراحل الست المنظمة (فهم الاحتياج -> التشخيص -> التصميم -> التنفيذ -> القياس -> التحسين).
   - **منهجيتنا المهنية** (Our Professional Approach): المبادئ والقيم الـ 10 الحاكمة لجودة العمل.
   - **المرجعيات والمعايير الدولية** (International References): مصفوفة المعايير والمواثيق العالمية (CHS, Sphere, OECD DAC, UNEG, HRBA, AAP, PSEA, CRC, CEDAW).
   - **مجالات الخبرة** (Areas of Expertise): 8 قطاعات تخصصية رائدة.
   - **القيمة المضافة والشراكات** (Value Proposition & Partnerships): محركات القيمة الخمسة، التموضع المؤسسي، والتزامنا، وبوابة طلب الاستشارات.

4. **المهارات المؤسسية المضافة من `C:\Category`**:
   تم نسخ وتثبيت 18 مهارة أساسية إلى مجلد `.agents/skills`:
   - `bilingual-technical-and-legal-translation` (الترجمة المتخصصة والمصطلحات القانونية والإنسانية)
   - `frontend-design`, `high-end-visual-design`, `ui-ux-pro-max`, `design-system`, `minimalist-ui`, `web-artifacts-builder`
   - `curriculum-knowledge-architecture-designer`, `professional-development-session-designer`, `scope-and-sequence-designer`
   - `landing-page`, `responsiveness-check`, `code-review-and-quality`, `debugging-and-error-recovery`, `git-workflow-and-versioning`
   - `strategy-document`, `audit-trail`

## 🚀 طريقة تشغيل المشروع في IDE

### الطريقة الأولى: فتح Workspace المخصص
1. من داخل Antigravity IDE أو VS Code، اختر:
   `File` -> `Open Workspace from File...`
2. اختر الملف:
   `C:\SHAT_Company\Shat-Company-Platform.code-workspace`
   (أو من مجلد scratch: `C:\Users\pc\.gemini\antigravity-ide\scratch\Shat-Company-Platform.code-workspace`)

### الطريقة الثانية: تشغيل خادم التطوير المحلي (Dev Server)
من داخل الطرفية (Terminal):
```bash
npm run dev
```
أو تشغيل خادم مباشر:
```bash
npx vite
```
أو فتح ملف `index.html` مباشرة في أي متصفح ويب حديث.
